# Lash Your Style (LYS)

Aplicativo profissional para lash designers focado em análise morfológica do olhar, construção técnica de mapping personalizado e simulação visual baseada em fios reais.

## Objetivo

Auxiliar profissionais a realizarem análises mais precisas, visualizarem possibilidades de resultado e construírem mappings personalizados de forma técnica e padronizada.

## Status do Projeto

Em desenvolvimento.

## Áreas do Projeto
- UX/UI
- Arquitetura de software
- Prototipagem
- Engenharia de requisitos
- Fluxos de navegação
- Simulação visual
