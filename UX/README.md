# UX Research

> Understanding people before designing solutions.

A experiência do usuário é um dos pilares do LYS.

Antes de desenvolver telas, algoritmos ou regras de decisão, o projeto busca compreender profundamente como clientes e lash designers pensam, sentem e tomam decisões durante o processo de extensão de cílios.

O objetivo desta documentação é transformar pesquisas qualitativas em conhecimento estruturado que possa orientar tanto o design da interface quanto a evolução da Mapping Engine.

---

## Objetivos

- Compreender as necessidades reais das clientes.
- Entender como lash designers tomam decisões.
- Identificar dores, expectativas e comportamentos.
- Validar hipóteses de produto.
- Fundamentar decisões de UX com pesquisa.
- Alimentar a Base de Conhecimento e a Mapping Engine do LYS.

## Processo de UX

O desenvolvimento segue uma adaptação do processo de Design Thinking utilizado durante o Google UX Design Certificate.

```text
Empathize
     ↓
Define
     ↓
Ideate
     ↓
Prototype
     ↓
Test
```

Cada etapa gera conhecimento que será utilizado para evoluir o produto.

---

## Relação com a Mapping Engine

O UX Research não existe apenas para criar interfaces.

Grande parte dos insights obtidos nesta etapa alimenta diretamente a arquitetura de decisão do LYS.

```text
Pesquisas
      │
      ▼
Insights
      │
      ├────────► UX
      │
      └────────► Mapping Engine
```

Dessa forma, o comportamento das usuárias influencia tanto a experiência do aplicativo quanto as decisões técnicas geradas pela engine.
